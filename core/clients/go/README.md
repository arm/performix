# Go Arm Performance Analysis Platform Client Package

Although there is a single Go module, we use the [multi-module pattern](https://github.com/golang/go/wiki/Modules#publishing-a-release)
for releases as the generated Go code is committed back to GitHub into a dedicated directory.


## Setup

Since this is a private repository inside `Arm-Debug`, configure Go and Git to
treat Arm-Debug repositories as private. Follow the shared
[private package access setup](../../../DEVELOPMENT.md#package-access) first.

1. Add `Arm-Debug` to `GOPRIVATE` with the following command 
   - `go env -w GOPRIVATE=github.com/Arm-Debug`

2. Configure git appropriately to use private repositories:
   - `git config --global url."https://<GitHub Username>:<GitHub PAT>@github.com".insteadOf "https://github.com"`



## Usage

Therefore, the Go package can be imported as follows:

`go.mod`
```
require (
	github.com/Arm-Debug/apap-cli/clients/go v0.3.1
	...
)
```

`*.go`
```go
import (
    ...

    "github.com/Arm-Debug/apap-cli/clients/go/apapproto"
)
```

## Development

With any change in the protobuf interface, the Go client generated code must be regenerated. For local development, run
this from the repository root:

```sh
task core:generate
```

This regenerates the Go protobuf outputs and mocks under `clients/go`. Pull requests and draft pull requests with
protobuf changes are also regenerated by the `Code Generation` workflow; pull the generated commit once it is
available on the remote branch. GUI TypeScript engine API bindings are generated with `task gui:generate`.

## Examples

In the examples directory you will find an `examples` package which includes example code that can be imported and run. A prerequisite for running example client code is to have the apap-engine gRPC server running.

1. Run the server: 

   See [the GitHub release page](https://github.com/Arm-Debug/performix-cli/releases) for the APAP CLI binaries. Download and install the binary for your platform and architecture, then use apx to start the gRPC server. 
   
   See also: [Performix Command Line Interface](../../README.md#performix-command-line-interface)
    ```sh
    apx daemon start
    ```
1. Run the client example code.

    Create a basic client module for the client example code called example_main.go:
    ```go
    // example_main.go
    package main

    import (
       "github.com/Arm-Debug/apap-cli/clients/go/examples"
    )

    func main() {
	    examples.RunExampleClient()
    }
    ```
    install "github.com/Arm-Debug/apap-cli/clients/go/examples"  
    `go get github.com/Arm-Debug/apap-cli/clients/go/examples`
   
    Run example_main.go
    ```
    go run example_main.go
    ```
