# Diagrams

This repo includes both source and exported diagrams. Two tools are recommended for generating diagrams (listed below),
for displaying in GitHub please export as `png` files.

## Plant UML (PUML)

Free declarative diagramming standard, which is also built into Confluence.

- [Online Documentation](https://plantuml.com/)
- [Download](https://github.com/jgraph/drawio-desktop/releases)

## Draw.io

Free online diagramming tool, which is also built into Confluence.

- [Online Editor](https://app.diagrams.net)
- [Intelli-J Plugin](https://plugins.jetbrains.com/plugin/7017-plantuml-integration) for GoLand, PyCharm etc.
